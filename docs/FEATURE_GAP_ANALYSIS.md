# NutriMenu AI — Feature Gap Analysis Matrix

This document provides a feature-by-feature verification across all application workflows, detailing observed behavior, evidence, status, and architectural justification.

| Feature Category | Intended Requirement | Existing Implementation | Status | Evidence File / Function | Action Taken / Justification |
|---|---|---|:---:|---|---|
| **Registration** | Email + password + profile initialization, password policy (>=8 chars, common blocklist) | Enforced on backend with Bcrypt hash, email normalization, rate limits | **Complete & Verified** | `backend/api.py:register_user` | Tested in `test_security_and_auth.py` |
| **Email Verification** | 6-digit cryptographic verification code sent via SMTP, single-use, 15m TTL | HMAC-SHA256 hashed code stored in DB, verified before activation | **Complete & Verified** | `backend/api.py:verify_email_address`, `backend/auth/codes.py` | Tested in `test_email_verification.py` |
| **Authentication & Login** | Brute-force lockout (10 fails = 15m lock), constant-time dummy verify | Enforced on backend with timing attack defense and IP rate limits | **Complete & Verified** | `backend/api.py:login_user`, `backend/auth/rate_limit.py` | Tested in `test_security_and_auth.py` |
| **Session Lifecycle** | 15m access token, rotating refresh token, single-flight mutex, 60s race grace window | Implemented in backend `rotate_refresh_token` and frontend `api.js` | **Complete & Verified** | `backend/auth/sessions.py`, `frontend/src/api.js` | Tested in `test_auth_sessions.py` |
| **Session Management UI** | View active devices, revoke single session, revoke all other sessions | Responsive table in Settings modal showing IP, device, and last active | **Complete & Verified** | `frontend/src/components/account/SessionsPanel.jsx`, `backend/auth/routes_account.py` | Tested in `test_account_management.py` |
| **Two-Factor Auth (MFA)** | TOTP authenticator (RFC 6238) + 10 single-use hashed recovery backup codes | Fernet encrypted TOTP secret, backup codes verified and popped on use | **Complete & Verified** | `backend/api.py:setup_mfa`, `verify_mfa_login`, `disable_mfa` | Tested in `test_mfa_and_password_reset.py` |
| **Password Reset** | Blind response (anti-enumeration), 6-digit OTP, global session invalidation | Hash-stored OTP, invalidates prior sessions on reset, rotates token version | **Complete & Verified** | `backend/api.py:forgot_password`, `reset_password` | Tested in `test_mfa_and_password_reset.py` |
| **Email Change** | Dual notification (notice to old address, confirmation to new address) | Reissues tokens, revokes other sessions, verifies ownership | **Complete & Verified** | `backend/auth/routes_account.py:change_email_request`, `confirm_email_change` | Tested in `test_account_management.py` |
| **Account Deletion** | 14-day grace period with unauthenticated restoration capability | Soft delete marker, cancels on login, automatic purge via maintenance | **Complete & Verified** | `backend/auth/routes_account.py`, `backend/maintenance.py` | Tested in `test_account_management.py` |
| **Audit Logging** | Tamper-evident logging of security events with IP, agent, and user ID | Stored in `audit_logs` table, sanitized (no passwords or secrets) | **Complete & Verified** | `backend/auth/audit.py:record_audit_log` | Tested in `test_account_management.py` |
| **Menu OCR & Vision** | Upload photo, extract dish names, sections, prices, and clean noise | EasyOCR / Gemini Vision pipeline with non-food filtering | **Complete & Verified** | `backend/api.py:start_menu_scan_job`, `src/pipeline.py` | Tested in `test_integration_pipeline.py` |
| **Clinical Health Matrix** | Synthesizes BMR, TDEE, macronutrient targets, and medical guardrails | Deterministic Harris-Benedict + Mifflin-St Jeor calculation with AI enrich | **Complete & Verified** | `src/matrix_generator.py:AIMatrixGenerator` | Tested in `test_matrix_generator.py` |
| **3-Tier Food Recommendation** | Categorizes dishes into 🟢 Good, 🟡 Medium, 🔴 Bad with allergen safety | Hard allergen exclusion (fit_score=0) prevents AI override | **Complete & Verified** | `src/recommendation_engine.py:TieredFoodRecommender` | Tested in `test_recommendation_engine.py` |
| **Saved Menus & History** | Persist scanned menus, private to authenticated user, soft/hard delete | Stored in `saved_menus`, cascade deletes uploaded menu image files | **Complete & Verified** | `backend/api.py:create_saved_menu`, `delete_saved_menu` | Tested in `test_security_and_auth.py` |
| **Meal Tracking & Logging** | Log dishes into daily meals, calendar tracking, CSV export | Stored in `logged_meals` table, downloadable CSV endpoint | **Complete & Verified** | `backend/api.py:create_logged_meal`, `export_user_meals_csv` | Tested in `test_security_and_auth.py` |
| **Distributed Scaling** | Multi-worker background job state and rate limit coordination | Redis sorted sets with automatic in-memory fallback | **Complete & Verified** | `backend/jobs.py`, `backend/security.py` | Verified with unit scripts |
